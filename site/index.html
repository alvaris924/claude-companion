for Claude Code.

Companion is a mod for Claude Code. It adds small, useful features right where you work, and it is built to keep taking more. It starts with your last prompt in view, next messages you can click, and the right model for each task.

Features so far

Helpers that live where you work

Companion is a home for helpers inside Claude Code, and these are the first ones. They show up in a quiet band above the prompt box, and you tune them in a settings pane you open when you want it. Each demo shows VS Code and the terminal, a tab apart.

Your question stays in view

A long answer can push your question off the screen. The band keeps it in sight while you read, without the blocks a host wraps around your words.

A pasted image shows as [image]. On the mobile app it’s a pane instead, and /last-prompt opens it again with the choices.

Suggestions you can click

After each answer, a model reads your prompt and the end of the reply, then offers what you’ll likely send next. You get three by default, or anywhere from one to five.

Click one to send it, or have a click put it in the box so you can edit first. In the terminal, every choice takes its own number from the empty prompt box, Tab takes the likeliest, and /copy-next 2 copies the second.

The right model for each task

Sonnet 5.5 grades each new task easy, mid or hard. By default it only suggests. Your task runs on your own model, and when another one would fit, up for hard work or down for an easy question, a button appears while the answer is still being written. Once the answer is in, a cheaper pick sends what follows there instead.

Turn on Automatic and it switches on its own: easy on Haiku 5.5, mid on Sonnet 5.5, hard on Opus 5.5 at max, each yours to change. Replies stay with their task, so a quick “why?” after hard work stays on the hard model. Each model keeps its own setting, so Automatic can run on Opus while Suggest stays on Sonnet.

Tune it in one place

Run /companion, or click ⋯ in the band. Pick the model that writes suggestions, how many you get, what a click does, and how each task’s model is fitted.

In the terminal it opens as a menu you work from the keys: ↑↓ to move, Enter to change, Esc to close. Every pick is saved for all your sessions, and open ones use it from their next turn.

Where it works

Wherever you run Claude Code

Companion draws with the elements each surface provides, so its features fit in wherever you run Claude Code.

Terminal
The band, cut to your window, numbered choices you pick by typing their number, and the settings as a menu you work from the keys.
VS Code
The band above the prompt box, each suggestion a quiet button and each switch a link.
Desktop app
The band above the prompt box, drawn the same way.
Mobile app
A pane with your last prompt and the suggestions.
No plugin UI
The suggestions as one line beneath the answer.
Headless runs
No suggestion call for claude -p or the Agent SDK, where nobody reads them.

Cost and privacy

What it sends, and what it costs

Companion runs inside Claude Code and uses your own account. Here is exactly what leaves your session.

1 call per answer

One model call, on your account

Each round of suggestions is one request through Claude Code, counted toward your plan or API bill like any other. If the chosen model gives no answer, Haiku 5.5 is asked once instead. Fitting the model to each task adds one short grading call when a new task starts.

1,500 + 6,000 characters

Only what it needs

The model sees your last prompt, up to 1,500 characters, and the end of the answer, up to 6,000. Nothing else from your session is sent.

0 requests of its own

No network requests

Companion calls nothing itself. Settings stay in Claude Code’s plugin store, and your last prompt and the suggestions live only in the session’s state.

Sonnet 5.5 by default

You pick the model

Haiku 5.5 is the cheapest and fastest. Fable 5.1 writes the best suggestions and costs the most, about 100 times Haiku’s price per token. Or turn suggestions off and keep the band.

Install

Ask Claude to install it

Paste this into Claude Code, in the terminal, VS Code or the desktop app. Claude clones the repository, reads the code and tells you what it found, then installs the plugin from that clone. Start a new session to load it.

Paste into Claude Code

Clone https://github.com/alvaris924/claude-companion into my home folder, check the code for anything unsafe, then install the companion plugin from it.

Updating

Keep the clone, since Companion is read from it. Run git pull there, and your next session uses the new code.

Or install it yourself

claude plugin install companion --marketplace alvaris924/claude-companion

From a shell. In a terminal session, /plugin install takes the same arguments.
