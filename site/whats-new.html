What’s new

Companion is a mod for Claude Code that adds small, useful features where you work. Here is what changed lately, and how to use each part.

  • Choose the grader
  • A grader that leans hard
  • A calmer band
  • Easy, mid and hard tasks
  • Settings in two groups
  • Install by asking Claude
  • Suggestions you can click
  • Sonnet 5.5 by default
  • Your last prompt in view

21 October 2026 v0.11.0

Choose the grader, or grade twice

Two new pickers sit in the settings group for each task. Grader sets the model that sorts a new task into easy, mid or hard: Sonnet 5.5 by default, or Haiku 5.5, Opus 5.5 or Fable 5.1, always at low effort. A stronger grader judges the tasks in between better and costs more per call.

Grading can ask twice. Both calls start at once and the harder grade wins, which smooths out the grader changing its mind between runs, about once in eight prompts. A hard grade ends the wait, and once one call has answered the other has 2.5 seconds, so a call that hangs never holds your task up.

  1. Run /companion.
  2. Under the task settings, pick a Grader, and set Grading to Two calls if you want the harder grade.
  3. Send a task. The band shows its grade as before.

Two calls cost twice the grading and the same wait. Short replies are never graded.

21 October 2026 v0.10.1

A grader that leans hard

The grader that sorts each task into easy, mid or hard was checked against 120 prompts typed in real sessions. It sorted them in the right order, with two slips: some requests to change or run something were graded easy, and on some runs a hard task got a mid grade.

Easy now means only a question, a lookup, a status check or a short explanation. Anything that edits files, runs commands, commits, merges or deploys is at least mid, and when a task could need hard-level reasoning the grader answers hard. A wrong easy grade gets a weaker model and a worse result, while a wrong hard grade only costs more.

On the same 120 prompts, easy grades that went on to take ten or more tool calls fell from 4 to 1 or 0. Expect a few more tasks on Opus 5.5 at max effort.

21 October 2026 v0.10.0

A calmer band above the prompt

The band reads like part of Claude Code now. Your last prompt sits as a quote, the suggestions are quiet buttons marked ↳, and a ⋯ at the end opens the settings. Every color comes from your theme, so it looks right in dark and in light.

  1. Send any prompt.
  2. When the answer ends, the suggestions appear under Suggested.
  3. Click one to send it, or set a click to put it in the prompt box first.

The terminal keeps its compact row of buttons.

Easy, mid and hard tasks, each on its own model

Turn this on and Sonnet 5.5 grades each new task easy, mid or hard. An easy one runs on Haiku 5.5 at low effort, a mid one on Sonnet 5.5 at medium and a hard one on Opus 5.5 at max, and you pick what each grade runs on.

  1. Run /companion.
  2. Set Fit model and effort to each task to On.
  3. Send a task. The band shows its grade and the model it runs on, and Ask again on Opus 5.5 brings back your usual model.

Replies stay with their task without a new grading, and an order after an easy question, like “yes” or “push it”, is graded as work of its own. It switches at any length of conversation unless you set a limit: in a long one, a switch makes the new model read the conversation once without its cache, so “Easy and mid tasks switch up to” 100,000, 200,000 or 400,000 tokens lets only hard tasks switch past it, and the band says “kept: long conversation”.

Settings in two clear groups

The settings pane groups its pickers by what they change, with a short note under each group, and each grade gets its own picker for the model and effort its tasks run on.

  1. Run /companion, or click ⋯ at the end of the band.
  2. Pick a value. It’s saved for every session.
  3. Open sessions use it from their next turn.

19 October 2026 v0.9.0 · First public release

Install it by asking Claude

Companion is public. Claude can clone it, check the code and install it for you, in the terminal, VS Code or the desktop app.

  1. Paste the prompt below into Claude Code.
  2. Read what Claude found in the code before it installs.
  3. Start a new session to load the plugin.
Clone https://github.com/alvaris924/claude-companion into my home folder, check the code for anything unsafe, then install the companion plugin from it.

Keep the clone: git pull there updates it. Companion needs Claude Code 2.1.300 or newer.

Suggestions you can click

After each answer, a model reads your last prompt and the end of the answer, then offers the messages you’re most likely to send next. You get three by default, or anywhere from one to five.

  1. Send a prompt and wait for the answer.
  2. Click a suggestion to send it as your own message.
  3. In the terminal, press Tab to take the likeliest one, or run /copy-next 2 to copy the second.

Sonnet 5.5 writes the suggestions

New installs ask Sonnet 5.5 for suggestions, so the most expensive model isn’t spent on every answer. Fable 5.1, Opus 5.5 and Haiku 5.5 are one pick away, and a model you already chose is kept.

  1. Run /companion.
  2. Under Suggested next messages, choose a Model and a Thinking effort.

Your last prompt stays in view

A band right above the prompt box shows what you last asked while the answer scrolls by. Text a host wraps around your words is left out, and a pasted image shows as [image].

  1. Send a prompt. It stays above the box until you send the next one.
  2. On the mobile app it opens as a pane. Run /last-prompt to bring it back after you close it.
